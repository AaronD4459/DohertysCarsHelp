Welcome to Doherty’s Cars Help Centre

This guide helps you use the Test Drive Booking System.

Topics

  • Adding Customers: Click “Add New Customer” and fill out the form.
  • Filtering: Use the search bar to find customers quickly.
  • Booking Test Drives: Go to “Book a Test Drive” and select an available slot.
  • Backing Up: Use the “Backup” button to save your data.
