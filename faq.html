Troubleshooting

The customer list isn’t showing new customers.

Click the Refresh button in the Customer Maintenance form. If it still doesn’t appear, ensure the new customer was saved successfully and that your database connection string is correct.

I get a database connection error.

Check that the database file Dohertys2025.mdf exists in your project’s App_Data or data directory. If using SQL Server, make sure the connection string in StaticClass.connString points to the correct path or instance.

The test drive booking says there’s a double booking, but the slot is free.

Ensure the Start Date and End Date are correctly set, and check that another booking doesn’t overlap even partially. The system prevents overlapping time ranges for the same salesperson or vehicle.

The backup feature gives an error about database in use.

Close any open SQL Server Management Studio or database browser windows. Then retry the backup. If the error persists, run the application as administrator to ensure file access permissions.

The program won’t open after moving it to another computer.

Ensure the database file is copied with the application. If you used a full SQL Server instance, install SQL Server Express on the target machine or use a local MDF file connection.

Frequently Asked Questions

Can I edit or delete customers?

Yes. Select the customer in the list and click Update Customer to change details. Deleting can be added by your administrator using SQL tools or future updates.

Can I restore data from a backup?

Yes. Replace your existing database file with the backed-up .mdf and .ldf files, then restart the program. The application will reconnect automatically.

What version of SQL Server does this use?

The system is designed for SQL Server Express, but it also works with LocalDB or a full SQL Server instance if your connection string is updated.

Where is my data stored?

All data — customers, staff, and bookings — is stored in the Dohertys2025.mdf database file located in your project’s data directory.

How can I get more help?

Visit the main Help Centre page or contact your project supervisor or system administrator for support.
