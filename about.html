Overview

The Doherty’s Cars Test Drive Booking System is a Windows application developed in C# (.NET, WinForms) to simplify and manage vehicle test drive scheduling. It provides tools for handling customer data, staff management, and test drive bookings with real-time validation and database integration.

Purpose: To streamline the test drive process by digitally managing customers, staff, vehicles, and bookings in one secure system.

Main Features

  • Customer Management: Add, update, and view customer information with validation.
  • Staff Records: Maintain an up-to-date list of staff who handle test drives.
  • Test Drive Scheduling: Prevent double bookings using smart availability checks.
  • Test Drive Management: Add, update, and view booking information with validation.
  • Filtering: Quickly find records using the live search filter.
  • Backup Utility: Export and back up the entire database with a single click.

Technologies Used

  • Language: C# (.NET Framework)
  • UI Framework: Windows Forms
  • Database: Microsoft SQL Server Express / LocalDB
  • IDE: Visual Studio 2022
  • Version Control: Git + GitHub
